# Screen2XYZ v2.7 quick start

## 1. Choose a capture mode

Pick live screen capture for continuously changing readouts, or load a PDF/image for plan clicks.

## 2. Map X, Y, and Z

Choose the source for each output column. Draw tight screen zones around values and use Test mapping before capture.

## 3. Start and watch zone health

Start capture, then work in the source application. The topmost overlay shows each live reading and pauses safely if a zone stops parsing.

## 4. Stop and review

Sort or filter the captured rows. Edits and deletions are audited and the original run journal remains preserved.

## 5. Export the result

Export XLSX or CSV, then validate preliminary results against an authoritative source before use.
