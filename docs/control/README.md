# Project Control

This directory is the operational entry point for parent-agent project orchestration.

Read in this order before every run:

1. `PROJECT_STATE.md` — current governed project state and authorization boundary.
2. `NEXT_ACTION.md` — exactly one recommended next controlled task.
3. `OWNER_DECISIONS.md` — decisions that only the project owner can make.
4. `ORCHESTRATION_WORKFLOW.md` — required parent/subagent workflow.

The approved Charter, current Master Index, Decision Log, repository history, and GitHub state remain controlling evidence. Chat history is supporting context only.
