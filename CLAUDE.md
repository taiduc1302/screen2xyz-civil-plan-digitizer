# Public research workflow instructions

Read `AGENTS.md`, the selected branch's README and `PUBLIC_RELEASE_AUDIT.md`.
Use synthetic inputs only in committed examples and tests. Put local real work
outside Git. Do not restore excluded operator data from an old clone or backup.
The public snapshot check and repository sanitization test must remain active.

Keep source PDF identity immutable, register an editable working copy, and verify
scale independently. Render and inspect each proposed measurement on the actual
feature; numerical agreement is not placement validation. Every proposal needs
source, rule, unit, identifier and review status. QA/reference shapes carry
`QA CHECK - DO NOT SUM` and are excluded from quantity rollups.

Discover the installed MCP tools and request schema before writes. Old sample
request shapes are not authority for a changed connector. Write only through a
verified current route, then save and read back native quantities. A markup plan
or generic polygon is not evidence of a native scaled Revu measurement.

AI may propose, measure and flag questions, not grant final estimator approval.
Use separate evidence for scale, geometry identity and printed-dimension checks.
Report missing capabilities and failed/skipped tests explicitly.
